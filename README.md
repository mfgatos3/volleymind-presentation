# VolleyMind & LifeLab • Presentación Oficial (Sustentación de Proyecto)

> **Presentación interactiva para la sustentación académica del proyecto "VolleyMind & LifeLab".**
> Desarrollada con **Reveal.js**, 8 temas visuales intercambiables en tiempo real con la tecla `T`, notas del orador integradas y enlace directo al simulador interactivo.

## ⌨️ Controles de la Presentación

* **Flechas de Dirección / Espacio:** Navegar entre diapositivas.
* **Tecla `S`:** Abrir la ventana de notas del orador (Speaker Notes con guion de sustentación oral).
* **Tecla `T`:** Alternar entre los **8 temas visuales** (RGB Gamer, Clean Corporate, Obsidian Gold, Cyber Cyan, etc.).
* **Tecla `F`:** Activar modo pantalla completa.
